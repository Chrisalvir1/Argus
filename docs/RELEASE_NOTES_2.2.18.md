# Release Notes - Argus v2.2.18

## Major Architecture Unification (React + TypeScript)
1. **Single-Layer Pure React Frontend:** Completely eliminated legacy multi-layered DOM injection and merged everything into a single responsive, reactive layer.
2. **tvOS Style Entrance Profile:** Redesigned entrance with large circular profile avatar, admin status, and smooth spring-bounce contraction into the top bar.
3. **Redesigned Liquid Glass Modals:**
   - **SOS Actions:** Dedicated modal with sirens, lights, and quick emergency trigger options.
   - **Access Control:** User and permissions management modal.
   - **Active Instances:** Real-time animated status with dynamic Shield SVG and siren alert lighting.
4. **Bug & Stability Fixes:** Cleaned legacy bridges, fixed TypeScript types, and ensured 100% CI pass rate.
