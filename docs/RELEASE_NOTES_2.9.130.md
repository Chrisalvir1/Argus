# Argus 2.9.130

Al mover o redimensionar un widget, el tablero compacta verticalmente los demás y cierra los huecos libres, con un comportamiento de reacomodo similar al de iOS. Mantiene las columnas escogidas por el usuario y los diseños separados para móvil, tablet y web.

Validación: contrato de configuración del grid, pruebas de frontend y compilación Vite.
