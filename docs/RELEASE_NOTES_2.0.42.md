# Argus Home Hub v2.0.42

- Los nombres visibles y TTS priorizan el título del dispositivo, sin repetir “Mostrar como”.
- La espera de sensores usa un estado ARMING real para que HomeKit siempre pueda enviar Off y cancelar.
- El botón verde DESARMAR / OFF recupera el ancho completo y su posición encima de SOS.
- El escudo vuelve a mostrar animación de espera y los sensores bloqueadores parpadean.
- El orden de widgets se captura antes de salir de edición y se conserva en almacenamiento local estable y Home Assistant.
- Se desactiva el adaptador React opcional que sobrescribía el orden del tablero nativo.
