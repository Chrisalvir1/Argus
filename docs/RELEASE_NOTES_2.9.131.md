# Argus 2.9.131

Se afinó la sensación del tablero al compactar widgets. Durante el arrastre y el redimensionado, las tarjetas vecinas siguen el cambio directamente, evitando que una transición larga se reinicie a cada paso. Al soltar, las posiciones y tamaños terminan con una animación corta, sin rebote exagerado.

Validación: compilación Vite, pruebas del contrato de layout y pruebas del frontend.
