# Release Notes - Argus v2.2.38

## Modernized UI & Dedicated SOS Configuration in Modos

### Highlights
- **Removed Obsolete Personalization Accordion**: Completely removed the legacy personalization/settings accordion from the alarm instance panel for a clean, streamlined console.
- **Dedicated SOS Configuration in Modos Widget**: Replaced the legacy "Vacaciones" mode with a dedicated **🚨 SOS** tab inside the Modos widget, allowing users to configure emergency contact numbers and map SOS output devices (sirens, lights, switches, scripts) directly.
- **Removed Vacaciones Mode from Alarm Instance Panel**: The alarm control panel card now focuses strictly on primary operational modes (En Casa, Ausente, Noche) with dynamic multi-column grid layout.
- **Home Name Editing in Profile Dropdown**: Users and administrators can now edit the home/household name directly from the user profile dropdown card (`Tu Perfil`) with master PIN security verification.
