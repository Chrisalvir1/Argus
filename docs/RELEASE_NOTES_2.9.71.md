# Argus Home Hub v2.9.71

- Argus now requires a disarm before switching between En Casa, Ausente, and Noche. The mode controls lock while armed, and the alarm entity also rejects mode changes from services and automations until disarmed.
- Locked mode choices appear gray while the selected armed mode remains colored. During SOS, mode selection stays locked until the SOS stop action is completed.
- Ausente is purple across the button, panel accent, status badge, security core, and corner guards. Red remains the active alarm/SOS color.
