# Argus Home Hub v3.7.0

- Mantiene abierta la verificación al seleccionar Todas las zonas.
- Presenta la verificación dentro de fullscreen con altura limitada y desplazamiento interno.
- Limita el contexto horizontal para evitar que invada la cabecera.
- Ordena fullscreen vertical: encabezado, núcleo, modos/SOS y contexto; respeta las áreas seguras del dispositivo.
- Permite regresar desde una zona seleccionada a todas las zonas que requieren atención.
- Incluye las mejoras anteriores de v3.0.6: configuración TTS directa, organización de selectores y ajustes responsive.

## Compatibilidad y validación

Conserva las configuraciones y el motor existentes. No cambia armado, PIN, SOS ni reglas de sensores.
TypeScript, build y pruebas frontend ejecutados para esta versión. La verificación visual física de estos últimos ajustes en iPhone y la instalación operativa sigue pendiente; no se presenta como aprobada.
