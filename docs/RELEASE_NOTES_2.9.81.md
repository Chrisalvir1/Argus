# Argus 2.9.81

Fullscreen limita el ancho de la consola y bloquea desbordamiento horizontal. Flecha y cuadro comparten una sola transformación elástica.

SOS abre automáticamente la pregunta de emergencias. Las alarmas por sensor muestran avisos de zona, nombre del sensor y estado Abierto. El cierre físico recoge el cristal, muestra Cerrado durante 1,8 segundos y retira el aviso; la alarma continúa activa. La llamada de emergencia se abre manualmente desde el botón inferior.
