# Argus v2.2.81 — Direct PDF Export, Diagnostic Summary, Wide SOS Selector & Official PIN Renaming

## Added & Improved
- **Direct PDF Activity Log Export:** The export history button now directly generates and downloads a formatted, multi-page `.pdf` document (`argus_historial_YYYY-MM-DD.pdf`) with complete event metadata, institutional header, and detailed audit records.
- **Unified Informative Status Card:** Combined SOS signals, notification channels, and audit log indicators into a single compact informative diagnostic card in Settings.
- **Full-Size Emergency Number & Wide SOS Selector:** The emergency phone card now matches the generous dimensions of the mode card, with a wide, spacious SOS device selector grid positioned directly underneath.
- **PIN Nomenclature Modernization:** Renamed "PIN Maestro" to **"Pin de Armado"** (*Arming PIN*) and "PIN de Acceso" to **"Pin perfil Argus"** (*Argus Profile PIN*) across all labels, settings, onboarding/first-run flows, modals, and localization dictionaries in 7 languages.
