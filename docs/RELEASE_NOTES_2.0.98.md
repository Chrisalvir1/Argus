# Argus v2.0.98 — Massive UI Simplification & Layout Fixes

This release introduces major UI simplifications and visual layout stability enhancements across the Argus dashboard:

1. **Re-enabled React Layout Permanently**
   The React grid layout is now permanently active and stabilized across panel views.

2. **Forced Text to White for Legibility**
   Text contrast and legibility are enforced with high-contrast white text across dark panels regardless of theme settings.

3. **Removed Complex Aesthetic Customization UI**
   Removed unnecessary visual customization controls in favor of a clean, consistent, and lightweight UI experience.

4. **Fixed Language Dropdown Selector**
   Fixed the language selection dropdown inside the profile menu to ensure smooth language switches and correct persistence.

---
*Summary of changes:* Massive UI simplification: Re-enabled React layout permanently, forced text to white for legibility, removed complex aesthetic customization UI, fixed language dropdown selector in profile menu.
