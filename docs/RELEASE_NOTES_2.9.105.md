# Argus 2.9.105

- El contenido de cada widget se adapta al ancho real de su propia tarjeta, tanto al reducirla como al estirarla.
- La navegación de Modos/SOS mantiene sus seis accesos en una sola fila compacta; el texto largo se recorta dentro del botón.
- Historial, Automatizaciones, Respaldo, Acceso, Modos/SOS y Soporte reorganizan controles y columnas para evitar desbordamientos.
- El núcleo de seguridad, sus cristales y sus animaciones no se modificaron.
