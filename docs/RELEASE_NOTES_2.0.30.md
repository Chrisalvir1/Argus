# Argus Home Hub v2.0.30

Esta versión consolida la reparación profunda de fondos, sensores y salidas de alarma.

## Correcciones principales
- Filas de sensores compactas y legibles, con estado de batería y desconexión preservados.
- Fondos independientes por perfil y retorno confiable al fondo predeterminado de Argus.
- Acciones SOS editables con color y destello por salida.
- Color y destello funcionales en los modos de alarma.
- Detección estricta de capacidades de luz: el color solo se ofrece a dispositivos de color reales.
- Compatibilidad de destello nativo y respaldo temporizado para dispositivos sin efecto incorporado.

## Validación
- Compilación Python completa.
- Suite de pruebas de regresión.
- Validación sintáctica de todos los archivos JavaScript.
- Validaciones HACS y hassfest del PR aprobadas antes de preparar esta versión.

> Después de actualizar, reinicia Home Assistant y realiza una recarga completa del navegador sin caché.
