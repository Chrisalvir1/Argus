# Argus v2.2.82 — Opaque Profile Dropdown, Direct PIN Modals, High-Contrast Badges & Wide SOS Layout

## Added & Improved
- **Opaque Frosted Profile Popover:** Deep non-transparent frosted background (`#0f172a` with `backdrop-filter: blur(48px) saturate(200%)`) eliminating background text bleed-through.
- **Direct PIN Configuration Modals in Profile:** Clicking "Cambiar" on Pin perfil Argus or Pin de Armado in the profile popover now directly opens the full interactive configuration modals.
- **High-Contrast Pure White Badge Text:** All user status and account badges (`CUENTA HA`, `PIN PERFIL ARGUS`, `INDEFINIDO`, etc.) now feature bright, pure white text (`#ffffff`) for maximum clarity and contrast on vivid colored backgrounds.
- **Wide Stacked SOS Mode Layout:** Full-size local emergency phone card with wide, spacious SOS devices selector grid positioned directly underneath.
