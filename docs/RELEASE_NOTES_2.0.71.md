# Argus v2.0.71 — Patch Release

## Added
- **Bienvenida y Animación de Resorte iOS:** Se rediseñó el ciclo de carga/login. Primero se despliega la pantalla de bienvenida con un rebote elástico. Después de un breve instante, la foto de perfil y el nombre ejecutan un vuelo fluido mediante interpolación y curvas bezier de resorte directo hacia su destino en la barra superior.
- **Píldora de Perfil Activo:** Nueva insignia flotante Liquid Glass integrada en el header (`hero-profile-pill`) que muestra la foto de perfil del usuario (o sus iniciales) y su nombre.
- **Atajo de Cambio Rápido de Perfil:** Al hacer clic sobre el distintivo de perfil en la barra superior, el usuario es redirigido directamente al modal de selección de perfiles para cambiar de cuenta al instante.

## Fixed
- **Reubicación de la Barra Superior (Hero):** Se reordenó toda la información del header para acomodar la nueva píldora de perfil de forma limpia y balanceada en pantallas de escritorio, tablets y dispositivos móviles.
