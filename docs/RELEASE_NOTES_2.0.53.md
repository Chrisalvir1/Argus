# Notas de la versión 2.0.53

Esta versión mejora sustancialmente la experiencia del usuario con notificaciones nativas ricas y mejor gestión de permisos.

### Nuevas características
* **Blueprints Nativos**: Ahora puedes importar notificaciones con video de 15 segundos para la Companion App de iOS y Telegram.
* **Badges de Permisos**: La interfaz de usuarios indica de manera proactiva qué accesos tiene cada usuario (Armar, Desarmar, etc).

### Correcciones
* **TTS Dinámico**: Reparada la regresión que silenciaba el conteo de sensores y descartaba cierres instantáneos.
