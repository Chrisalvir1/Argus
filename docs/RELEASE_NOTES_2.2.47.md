# Release Notes v2.2.47

- **Fullscreen Close / Stage Purge:** Fixed fullscreen exit listener and guaranteed stage purge on close to prevent black screen lock.
- **Web Desktop Fullscreen:** Removed constrained aspect-ratio and max-width in desktop fullscreen mode so it fills 100vw/100vh.
- **Portrait Mobile HUD:** Vertically stacked Home Name, Conectado indicator, and System State pill to prevent overlap on phones.
- **Dynamic Disarm Button:** Injected full-width 3-column span Disarm button when the system is armed.
- **Activity History & PDF Export:** Restored Activity History actions (Refresh, Export, Clear) and added absolute origin prefix for the Argus Home Hub logo in PDF exports.
