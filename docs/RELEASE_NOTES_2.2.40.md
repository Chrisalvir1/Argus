# Release Notes - Argus v2.2.40

## Highlights
- **Pestaña y Configuración SOS**:
  - Actualizado el nombre de la pestaña en el widget de Modos a **`CONFIGURACIÓN SOS`** para máxima claridad.
  - Asegurada la ejecución completa de todas las configuraciones SOS al deslizar la barra de pánico en la consola principal de seguridad:
    - Encendido y activación inmediata de todos los dispositivos de salida SOS seleccionados (luces estroboscópicas, sirenas, interruptores y scripts).
    - Notificaciones push de alta prioridad con sonido de alerta crítica al teléfono móvil.
    - Marcación rápida con el número local de emergencias configurado.
    - Registro inmutable en la línea de tiempo forense.
- **Exportación Completa de Historial**:
  - Diálogo de exportación en PDF imprimible con membrete oficial y selector de rango de fechas.
  - Descarga de reportes tabulados en formato texto (`.txt`) y datos sin procesar (`.json`).
- **Seguridad en Historial**:
  - Protección de borrado de historial mediante validación de PIN maestro cuando está configurado.
  - Registro de auditoría del usuario que ejecutó la eliminación de registros.
- **Mejoras Visuales**:
  - Contraste perfeccionado en color blanco `#ffffff` para el badge de PIN y chips de notificación.
