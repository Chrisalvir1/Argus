# 🚀 Argus is now OFFICIALLY in default HACS!

We are incredibly excited to announce that **Argus Home Hub** has been approved and merged into the default HACS repository. Along with this milestone, we are releasing **Version 2.0.0** today! 🎉

## 🛡️ Key Features & Updates in 2.0.0
- **Official HACS Integration:** You no longer need to add a custom repository URL. Simply search for "Argus" in HACS!
- **Community & Social Links:** Added official community channels and social media profiles to the README.
- **Support the Project:** Added a PayPal donation link for those who want to support the ongoing development of Argus.
- **Zero-Leak Privacy & Local Security:** Continuing our commitment to fully local processing and strict HA admin permission requirements.
- **Cinematic Weather-backed UI:** The beautiful WebGL atmosphere remains faster and more reliable than ever.
