# 🛡️ Argus v2.0.3: Active Security Console & Personal Disarm PINs

We are excited to deliver **Argus v2.0.3**, featuring an active security console UI and personal disarm PINs! 🎉

## 🌟 What's New in 2.0.3

- **🛡️ Active Security Console:** Redesigned active instance view inspired by premium security hardware consoles, retaining real Home Assistant entities, sensors, and arming modes.
- **🔢 Personal & Authorized Disarm PINs:** Support for individual disarm PINs per enabled Argus user with the `disarm` permission. Accepts global, guest, or user-specific PINs while strictly protecting hashes from frontend leaks.
- **🖥️ Fullscreen & Navigation Fixes:** Standard fullscreen toggling via `Esc` key without accidentally triggering Kiosk Mode lock.
- **📜 Cleaned Interface Layout:** Prevented duplicate activity history under active instances and ensured mode selection controls are non-blocking.
- **🌧️ Weather & Animations:** Realistic downward rain and weather atmosphere matching active local Home Assistant entities.
